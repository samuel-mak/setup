

# X Window System application configuration
~/.Xresources is a symlink to ~/projects/setup/config/.Xresources, which contains 
configurations for all X Window System applications (i.e. XTerm). Since GNOME doesn't 
automatically source config files for X Window System applications after booting, a 
startup system is created, there's a xresources.desktop startup file in ~/.config/autostart,
in this file, it has a linked sh file which is in ~/projects/setup/scripts/xresources.sh. On startup, GNOME will find this desktop file in the autostart directory, and execute the linked sh file. It seems like .Xresources file need to be in ~/, so using symlink to 
circumvent.

Okay, not a symlink anymore, desktop is pointing to the actual sh file

Steps
1. SSH keys
	- Get a copy of .ssh directory from storage to home
	- Run `chmod 700 ~/.ssh && chmod 600 ~/.ssh/*`
	- Can do all of these by putting the .ssh directory in a usb with a shell script to automate this
2. Get git 
	- If using apt, then run `sudo apt update && sudo apt install git`
3. Clone `setup` git repo from github 
	- Run `git clone git@github.com:samuel-mak/setup.git` in any directory in home
4. Folder structure and files (e.g. git repos) 
5. Installs 
6. Application configuration
7. Desktop configuration
